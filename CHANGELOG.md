## [1.0.0] - 2023-01-01

### Added
- Initial firmware for ESP32 / Heltec WiFi LoRa 32 V2
- MPU6050 IMU-based angle measurement for specific gravity calculation
- DS18B20 temperature sensor support with compensation
- Calibration wizard (Plainwater and Reference methods)
- Web UI with OTA firmware update
- Bluetooth Low Energy (BLE iBeacon) data broadcast
- Wi-Fi client and access-point modes
- Cloud integrations: Brewfather, Brewer's Friend, Brewblox, Grainfather, MQTT, HTTP, Google Sheets, Ubidots, Telegram, BierBot Bricks, iRelay Display
- Alert / notification system
- Deep-sleep mode for extended battery life
- Backup and restore of device configuration
- Customisable language via Web UI
- KiCad PCB design (v1.0) with production-ready Gerbers and BOM
