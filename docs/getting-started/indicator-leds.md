# Indicator LEDs



![Position of LED pairs](../assets/images/Folie36.png)

## Status LED of the Hydrom Logic

The Status LED shows the current operating state. When the Hydrom is in configuration mode, the LED is green. If something has gone wrong, only the red LED is lit.

## Charging LED

The Charging LED indicates battery state. If the battery is fully charged, the green LED is on. When the battery is charging, the red LED is on.
