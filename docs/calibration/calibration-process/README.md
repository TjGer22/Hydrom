# Calibration Process

This section describes the available methods to calibrate the Hydrom. For an overview of when calibration is needed and how to choose the right method, see [When and Why to Calibrate](../check-calibration.md).

## Available Methods

**[Quick Method – Plainwater](../../services/plainwater.md)**
Takes about 5 minutes. Only requires clean water at 20 °C. Suitable for most users.

**[Accurate Method – Reference](reference-method.md)**
Takes 1–2 hours. Requires a reference hydrometer and sugar or active wort. Produces the most accurate calibration curve across 7 density points.

**[Manual Formula Entry](manually-change-the-formula.md)**
If you have already calculated a polynomial calibration formula externally, you can enter it directly into the web UI.
