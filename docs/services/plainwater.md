# Do PlainWaterCalibration

!!! tip
    **Prerequisite:**

    1. user interface access\
       To make this setting, you must have access to the user interface. If this is not the case, see here how to do it: [Access the Userinterface](../troubleshooting/webui-unreachable.md)
    2. Equipment needed:
       1. water tank in which the hydrom can float.

1. place the hydrom in 20 degrees cold water and navigate to "Calibration
2. Activate the "Plainwater method".
3. Confirm the calibration with "Start".
4. The Hydrom measures the current position and compares it with the reference measurement values.
5. If there is an error message saying that the angle is over >90 degrees, please perform a position sensor calibration. This has only been necessary for a few customers so far and only occurs after the update to 1.5.1. [Do Attitude Sensor Calibration](../calibration/attitude-sensor-calibration.md)
6. The Hydrom now has a new calibration.
