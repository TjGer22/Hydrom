# Charging the Hydrom



The Hydrom can be charged with any commercially available USB-C charging cable.

Even the direction in which you insert the plug into the device does not matter. To charge, open the Hydrom by twisting off the lid.

The charging LED (described here: [Charging LED](../getting-started/indicator-leds.md#charging-led)) indicates the current charging status. If the LED is red, the Hydrom is being charged. When the LED is green, the charging process is complete.\\
