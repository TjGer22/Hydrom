# Contributing

Contributions of all kinds are very welcome — firmware improvements, new service integrations, hardware revisions, documentation fixes, and translations.

Please read the full [Contributing Guide](https://github.com/TjGer22/Hydrom/blob/main/CONTRIBUTING.md) in the repository root before opening a pull request.

- [Open a Hardware Issue](https://github.com/TjGer22/Hydrom/issues/new?template=hardware_issue.md)
