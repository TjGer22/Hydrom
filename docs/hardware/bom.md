# Bill of Materials

The full Bill of Materials (BOM) is available as an XLSX file in the repository:

📄 [`hardware/production/bom/BOM.xlsx`](https://github.com/TjGer22/Hydrom/raw/main/hardware/production/bom/BOM.xlsx)

The BOM includes reference designators, component values, footprints, LCSC/JLCPCB part numbers, and quantity per board.

## Sourcing

The BOM is optimised for ordering from **JLCPCB** with SMT assembly. Most components are available from the JLCPCB basic parts library, which significantly reduces assembly cost.

If you are self-sourcing components, equivalent parts from Mouser, DigiKey or LCSC can be substituted — check the datasheet for pin-compatible alternatives.
